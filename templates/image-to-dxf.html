Image to DXF

Extract outlines from images for use in CAD.

Background

I was working on a slim wallet which required a money clip style spring. Given that these springs are relatively wide and flat, it seemed like a good place to add something decorative to the design. I decided to use the outline of a Cottonwood leaf (my favorite tree) as this decorative element. To do this, I needed to get the Cottonwood leaf outline into FreeCAD. I had done a little bit of edge detection using OpenCV2 before, and thought this would be the easiest way.

Overview

The program is comprised of two stages.

preprocess_image.py is the first stage, and its purpose is to give the user a paintbrush to paint the outline of the object which they would like to capture. The rest of the image is heavily blurred to make it invisible to the edge detection algorithm.

The second stage is where the object contour is captured. img_to_dxf.py performs a common edge detection sequence:

  1. Convert the image to grayscale
  2. Apply a small amount of blur
  3. Perform Canny edge detection
  4. Morph together the edge segments into closed contours
  5. Display and capture the largest of the closed contours The program exposes all of the input parameters required for these steps to the user. Using sliders, they can fine tune the inputs to achieve the contour they desire.

pipeline.py simply knits together the two stages for ease of use.

In the end, the saved DXF can be imported into most CAD softwares, where it can be edited, resized, and used to create solids.

Usage

Place the image you would like to operate on in ./originals/ and then run
$ python3 pipeline.py

Instructions will be given in the command line. Whenever image manipulation is being performed, press “s” to save the image, and “q” to quit the current step and move on to the next.

Dependencies

Acquiring Dependencies

On Ubuntu, the system Python installation is managed by the OS, and so the OS package manager is used to install Python packages.
$ apt install python3-ezdxf python3-numpy python3-opencv

Other systems may use the Python package manager to install each of these.
$ pip install {package}
